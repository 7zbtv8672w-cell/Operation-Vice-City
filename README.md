# Operation Vice City V8

A mobile-first Progressive Web App (PWA) for the GTA VI launch command centre.

## Included
- Vice City pink/orange sunset theme
- Original 18-department navigation
- Live countdown while the app is open
- Intelligence notes and official Rockstar link
- Exploration counters and journal
- Launch session controls and editable schedule
- WiZ scene planner (not physically connected)
- Xbox reliability log
- Station checklist, supplies, budget, map notes, achievements, stats, gallery, notifications, emergency notes and crew planner
- Local browser storage and offline app shell

## Install on iPhone
1. Host the contents of this folder on an HTTPS website (for example GitHub Pages or another static web host).
2. Open the website in Safari on your iPhone.
3. Tap Share -> Add to Home Screen.
4. Enable "Open as Web App" if shown, then tap Add.

## Important limitations
This app does not connect to Rockstar, Xbox, WiZ or external notification services. Those integrations require separate authorised services and configuration. The app stores your entries in the browser on that device. Clearing website data may erase them; export important notes regularly.
